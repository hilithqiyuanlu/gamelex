# GameLex 0.3.0 同学试用

用于已安装大气层和 Ultrahand 的第一代 Switch。打开工具识别英文，选择一组文字后才翻译，还能在原句中选词查询。它不会暂停游戏，也不是完整汉化工具。

这是小范围试用版。此前实机记录来自一台 OLED；0.3.0 分组流程尚待实机确认，其他机型、固件、大气层、UH 及加载器组合都需要实际测试。离线词典、生词本、自动固定搭配和输入键盘尚未提供；目前词语查询仍是在线翻译。

## 一、安装

先将下载的压缩包完整解压到电脑。`sd` 是需要放入卡中的内容，不要把 `sd` 这层文件夹本身复制进卡。

**推荐带备份安装（电脑需要 Python 3.9 或以上）：**

在解压目录打开终端，先预览，再安装。Windows 示例假设卡为 E 盘：

```powershell
python tools/deploy.py --sd E:\
python tools/deploy.py --sd E:\ --apply
```

Mac 示例，替换成实际卡名：

```sh
python3 tools/deploy.py --sd "/Volumes/卡名"
python3 tools/deploy.py --sd "/Volumes/卡名" --apply
```

安装器只复制清单中的 GameLex 文件，先备份旧文件，保留已有 `config.json`。不替换 UH、加载器、大气层，也不修改 UH 的快捷键或设置。

**也可手动安装：** 将 `sd` 内的 `atmosphere`、`switch`、`config` 文件夹合并到卡根目录。一定是“合并”，不要替换整套目录。已有 GameLex 时先备份自己的程序和配置。首次安装，把 `config/gamelex/config.example.json` 复制一份并命名为 `config.json`；已有配置则保留原文件。

试用包包含 GameLex 后台的自动启动标记 `atmosphere/contents/42000000474C4558/flags/boot2.flag`，会占用后台内存；完整重启进入大气层后生效。只复制 `.ovl` 文件不能完成安装。卸载方法见下文。

## 二、填写自己的服务配置

用文本编辑器打开卡内 `config/gamelex/config.json`，只需填写以下四项的引号内容：

| 字段 | 填什么 |
| --- | --- |
| `ocr_api_key` | 百度文字识别应用的 API Key |
| `ocr_secret` | 同一文字识别应用的 Secret Key |
| `translate_appid` | 百度翻译服务的 APP ID，保留字符串引号 |
| `translate_key` | 对应的翻译密钥 |

OCR 应用需开通“通用文字识别（标准含位置版）”。同时开着“标准版”也可以，程序只调用含位置版一次。翻译使用文本翻译服务，需要自己有相应权限和额度。不要把 OCR 密钥和翻译密钥混填。

其他字段先保留默认值；`endpoint`、`api_key`、`model` 是早期诊断入口字段，当前百度流程不用填写。不要删除逗号、引号或大括号。配置解析失败时可重新从示例复制后填写。

**包内没有开发者密钥，不能开箱免费调用。** OCR 与翻译请求使用配置者自己的服务额度；没有自动重试，手动重新识别或重新翻译可能再次计费。已发出的请求即使在工具中取消，也可能计费。

安全弹出卡、插回 NS，并完整重启；更新程序后也要重启，不能只重新打开浮层。

## 三、怎么玩

1. 游戏停留在英文对话、任务日志或物品说明，打开 UH，点击 GameLex，自动截图并识别。
2. 左侧显示英文文字组。上下或左摇杆选择，A 翻译这一组；触屏可以拖动列表或点组。
3. 连续正文被拆开时，R 向后多选一组，L 缩回，再按 A。最多合选八组，不跨栏纠正时请留意预览内容。
4. 阅读页 X 切换原文／译文，Y 在英文中选词，方向键移动、A 查询；L/R 缩扩相邻词，触屏也可点英文词。
5. B 从查询返回原句，再 B 返回文字组，选择和滚动位置保留。当前截图缓存范围内，已翻译的组再次进入不重复请求。
6. 列表中 + 重新识别；等待时 B 取消。列表 B 返回游戏，下次组合键应打开正常 UH。

先试短对话，再试较长说明。默认不会过滤游戏里的数字、人名或菜单，背景图案仍可能误识别；选中需要的组即可，不会自动翻译其他组。游戏画面变化后需手动重新识别。

## 四、常见问题

- **版本不一致：** 重新安装同一个完整试用包并完整重启，浮层和后台必须配套。不要混用旧 `.ovl` 和新后台。
- **后台无响应或启动失败：** 核对后台文件与自启标记，完整重启。若仍失败，请记录错误码、UH／加载器版本和其他常驻模块；不要先替换自己的系统环境。
- **未配置、鉴权或额度错误：** 核对四项字段、标准含位置 OCR 权限与服务额度。OCR 和文本翻译是分别配置的。
- **联网超时或证书错误：** 检查主机网络和日期时间，之后手动重试；工具保持证书校验开启。
- **文字分错组：** R/L 合选与缩回；请反馈游戏名、页面类型和具体哪几行被分开或混入。

## 五、卸载与恢复

关机取卡，在解压目录运行以下命令，路径替换成实际卡：

```sh
python tools/uninstall.py --sd E:\
python tools/uninstall.py --sd E:\ --apply
```

Mac 使用 `python3` 和 `/Volumes/卡名` 路径。第一条只预览，第二条先备份，再移出本工具的浮层、后台、自启标记和诊断应用；配置及数据保留，不处理其他模块。之后完整重启。

手动卸载只删除 `switch/.overlays/gamelex-probe.ovl`、`switch/gamelex-device-probe/` 和 `atmosphere/contents/42000000474C4558/`。保留 `config/gamelex/` 即保留配置和诊断记录。若更新后开机异常，也可关机取卡，先移走上述 GameLex 模块目录，再启动原来的系统。

安装与卸载备份位于 `config/gamelex/backups/`。恢复时把对应目录中的旧程序文件放回原路径并完整重启，不要同时运行两套 GameLex 后台。

## 六、反馈

请填写随包的 `反馈模板.md`，先验证连续五次识别、选组翻译、查词返回、取消后再次识别，以及退出后再次呼出 UH。

不要发送 `config.json`、整份 SD 卡或整个 `config/gamelex` 文件夹。默认 `save_last_capture=false` 不保存诊断截图，但运行消息仍会包含最近识别的游戏文字；是否分享游戏照片由你自行决定。

包内 `gamelex-0.3.0-source.zip` 为对应源码与许可，`SHA256SUMS.txt` 为文件校验值。本版仅供自愿试用，不代表已通过全部实机验收。
