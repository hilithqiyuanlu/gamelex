# GameLex 0.3.0 实机测试

本版把操作改为：**打开即识别 → 选择英文文字组 → 只翻译所选内容 → 在原句内查词**。不再先显示“识别当前游戏画面”菜单，也不自动翻译全屏。

同学首次试用请先读 [同学试用.md](同学试用.md)。试用包包含自己的后台自启标记，不更换 UH 或加载器，不附开发者密钥。当前候选版新增前后台配套检查，更新时必须一起更新并完整重启；模块边界和发布方式见 [模块与发布.md](模块与发布.md)。

## 安装后使用

1. 安全弹出 SD 卡，插回 NS，完整重启进入大气层虚拟系统，让新版后台运行。
2. 游戏停留在英文对话、任务日志或物品说明；从 Ultrahand 点击 GameLex，立即进入截图与识别。
3. 截图时工具短暂透明，截图完成后恢复等待提示。识别完成，左侧显示英文文字组，每组最多预览三行；完整原文仍会保留。
4. 默认选中第一段较长正文。上下键或左摇杆切换，A 翻译选中组；触屏可滚动、点选文字卡片。
5. 若连续正文被拆成两组，R 向后扩选，L 缩选，然后 A 翻译。触屏也可点列表下方的扩缩操作。一次最多八组、总文本不超过 5000 字节。
6. 阅读页先显示所选英文，译文完成后自动显示中文；若已在滚动或选词，则保持当前视图，按 X 切换中英。没有把其他组混入这次翻译。
7. Y 在英文原句内选词；方向键移动焦点，A 查询，L/R 缩扩相邻词，最多六词且不跨标点或段落。触屏点英文词也可查询。这里的扩词是手动范围选择，不是自动固定搭配识别。
8. 词语页 B 回到原句，保留选词位置；阅读页 B 回到文字组列表，保留组选择和滚动位置。
9. 分组列表中 + 重新截图识别；列表下方也有触屏入口。刷新取消或失败，原来的组和译文仍保留；成功取得新结果后才替换旧内容。
10. 分组列表 B 返回游戏，下次组合键应打开正常 Ultrahand。等待时 B 取消并返回列表；没有识别结果时，A 可重新识别。

阅读页翻译失败时可按 + 手动重试、按 - 查看详情。没有自动重试收费请求。取消等待不保证服务端停止已经开始的计费请求。

## 分组与成本

- 默认使用百度 **通用文字识别（标准含位置版）** `/v1/general`。保留标准版权限也可以，但本流程不会再调用标准版一次，不会两种接口重复识别。
- 同一行的近邻碎片先拼合，再根据对齐、相对字高、行距与横向重叠合并连续行。字号明显变化、较大空白或不同文字列分开。
- 列表按栏排列，完成左栏再到右栏，方便 R 合并同一栏的相邻段落。位置缺失的文字保留为独立组，不猜测坐标。
- 默认正文选择只是便利规则；没有删除菜单、数字、单字母或疑似乱码。游戏图标仍可能被 OCR 误认，用户可以不选择、不翻译它们。
- 只有打开所选组的阅读页才发起翻译。当前截图最近八个选择范围的阅读结果会保留在内存中；相同范围再次进入，已有译文不重新请求。退出工具或刷新成功后不保证继续保留。
- 同一截图各组共用查词缓存，最多 64 条、约 16 KiB；整组缓存和查词缓存均有上限，避免占满浮层内存。

## 本轮证据与重点检查

卡上 0.2.6 最近一次启动记录：11 次 `scan_ok`，没有 `scan_error`。这证明上一版在这段使用记录中的连续识别已成功，不代表完成了 50 次实机稳定性验收。

使用卡上最后一张游戏截图做了一次实际 OCR，得到 41 条位置结果。当前规则把左侧三行、四行正文分别合为两组；标题、署名和右侧菜单保持分开。默认选中第一段正文，R 可合选下一段。截图及原始回复仅保存在工程私有备份中，没有放进安装包或源码包。

本机测试包含核心、阅读、分组、安装、协议、发布、HTTPS 和实际浮层代码的流程检查。流程检查使用平台替身，覆盖自动截图入口、列表不发翻译、只提交所选文本、缓存、查词返回、触屏点选／拖动、扩缩选择、过期回复、刷新失败保留旧结果，以及手指按住时识别完成后的返回。它不能模拟 NS 的真实触屏、VI 画面或原生 TLS。

NS 本次重点验收：

- 点击 GameLex 后无需再确认识别；截图仍是干净的完整游戏画面。
- 列表中的正文合并合理，左右栏不混合；文字卡片可选择，预览截断不影响完整原文。
- 选中一组只翻译这一组；B 返回后选择、滚动不丢失，再次进入已译组不等待新翻译。
- R 合选两段、L 缩回、触屏拖动再点选、英文选词和查词返回均正常。
- + 刷新、等待时取消、断网失败后返回，均可继续使用；旧回复不覆盖新结果。
- 反复识别与开关后，B 返回游戏、再次呼出 Ultrahand，无输入卡住或持续内存增长。

## 截图、内存与诊断

保留标准 448×720 侧栏、双缓冲和 4 MiB 后台堆。GameLex 层不参与截图和录屏；截图期间也不绘制通知层，连续提交透明帧后，后台核对本次编号和时间再截图。原始 JPEG 不解码重压，按实际大小释放空余容量，分块编码上传，每次请求后释放连接；HTTPS 证书验证保持开启。

设置仍保存在 SD `config/gamelex/config.json`，安装不覆盖既有密钥。Mac 私有配置为 `config/config.local.json`。Ultrahand 的启动通知已在此前安装中单独关闭，本版不改其快捷键或其他设置。

- `gamelex-boot.log`：本版标记 `appInit version=0.3.0`，以及识别／查询错误。
- `config/gamelex/runtime/overlay-safe.log`：截图、`groups_ready_no_translation`、选组翻译及退出记录，不含密钥。
- `scan-metrics.json.a`、`.b`：识别行数、分组数、截图／授权／OCR／翻译耗时、阶段堆占用和实际上传字节。采样点不是完整峰值跟踪。
- `backend.json.a`、`.b`：版本与后台运行状态。
- `overlay.response.json.a`、`.b`：本次响应；原始行、分组文本及坐标，或当前选择的译文。以封装中最大的 `sequence` 为准。

`save_last_capture` 默认 false。本轮设备仍启用 true，覆盖保留一张 `last-capture.jpg`；新增 `last-ocr.json` 覆盖记录最后一次取得的 OCR 回复，含图片字节数及字节指纹，便于核对是否对应同一截图。截图失败或请求取消时，两者可能对应不同轮次，应核对指纹，不可直接混用。验证后可设回 false，并删除这两份诊断文件。它们不进入日志、导出或发布包。

## 验证边界与回退

0.3.0 尚待用户 NS 实机确认，不能用构建与本机检查承诺“丝滑”或游戏兼容性。当前查询仍是在线翻译，尚无离线词典、自动短语匹配、生词本和系统键盘。

安装脚本仅更新清单中的 GameLex 文件，覆盖前自动备份，保留配置。回退时从 SD `config/gamelex/backups/` 对应目录恢复旧的浮层与后台，并完整重启。卸载可移除 `atmosphere/contents/42000000474C4558`、`switch/.overlays/gamelex-probe.ovl` 和诊断应用；保留 `config/gamelex/` 即保留设置。不修改其他模块或虚拟系统。
