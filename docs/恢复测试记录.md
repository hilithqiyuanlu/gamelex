本轮先隔离变量，不能把“之前能工作”忽略掉，也不能宣布 TLS 已修好。

- SD 当前证书与更新前备份逐字节一致，排除了更新时替换了不同证书这一项。
- 恢复更新前后台代码并重新构建，生成的 `gamelex-sys.nsp` 与 SD 备份 `20261019T135855384683Z/atmosphere/contents/42000000474C4558/exefs.nsp` 逐字节一致，SHA256 为 `ac1d78e3a86ad896abec3e7229e94d033a77b113b29beda5b082827cc89d3f88`。

- 为减少原生绘图的内存，使用一个像素缓冲和按状态变化重画，关闭过渡动画；单缓冲是否闪烁、实际内存是否稳定必须实测。`runtime/overlay-render.log` 记录初始化阶段堆占用，未记录截图或密钥。

- 共享绘图转换及坐标、换行、翻页等主机检查共 36 项通过。构建和测试不是实机验收。

为恢复精确后台基线，0.2.1 中的“旧请求检查、去掉逐行补发”本轮也一起回退了。它们后续应单独恢复和验证；当前不是功能验收完成版。
