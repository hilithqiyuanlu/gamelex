# 0.2.1-ui1 界面修复记录

2026-10-19。修复前源码备份：`.backups/ui-fix-20261019-214954/`。`HANDOFF.md` 保持原样；本记录补充本轮变化。

## 已确认的问题

- 自定义界面没有设置全屏绘图尺寸，库默认创建 448×720 侧栏；OCR 的整屏坐标被乘以侧栏宽度，框和触摸都落在错误的位置。
- 全部翻译原先将每行英文和中文用箭头拼接，放进仅约 149 像素宽的面板，长文本和滚动都难以阅读。
- 自定义全屏界面仍走默认侧栏的页眉、页脚触摸与焦点处理，可能触发退出或确认，触摸后手柄焦点也不可靠。
- 翻译请求缺少后台旧结果检查；界面显示缓存但重复点词仍发新请求。

卡上旧版记录包含 20 个文字框、13 行原文及 13 段译文，说明这次样本已经完成识别、翻译。未为本次界面检查额外调用收费服务，也没有复制密钥到安装包。

## 代码变化

- `switch/overlay/source/main.cpp`：选词画面、查词面板、纯译文阅读页；触摸松开才触发；面板区域拦截点击；翻页范围受限；失败可返回、手动重试；按请求编号接收一次结果；按词和整屏缓存。
- `core/include/gamelex/ui.hpp`：坐标投影、边界校验、最近文字框点选、中文换行、翻页和请求编号判断。`tests/ui_tests.cpp` 有 32 项检查。
- `vendor/libultrahand/libtesla/include/tesla.hpp`：新增仅由 `GAMELEX_FULLSCREEN_CANVAS` 启用的适配：640×360 画布铺满屏幕，触摸坐标转换，绕过侧栏输入区域；使用系统内置简体中文字体作为后备。宏由 `switch/component.mk` 对浮层所有编译单元统一设置，避免同一库出现不同尺寸定义。上游默认行为保持不变。
- `switch/sysmodule/source/main.cpp`：词语与整屏翻译只发布当前请求的结果。
- `switch/sysmodule/source/baidu.cpp`：整屏译文作为文档显示，分段数量不一致时直接使用返回段落，移除逐行补发请求。
- `scripts/package.py`：安装包版本更新为 `0.2.1-ui1`，仍标记实机验证待完成。

名义双缓冲像素大小从 448×720×2×2 字节降至 640×360×2×2 字节；这不是实测进程峰值，实际还包含对齐、字体和其它分配。没有提高系统内存或超频设置。
