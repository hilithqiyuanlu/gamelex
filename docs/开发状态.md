# 开发状态

当前候选版 **0.3.0**：打开 GameLex 即识别，按位置分组，用户选择后才翻译。`HANDOFF.md` 按用户要求保持原样，以当前源码及本文件补充后续进展。

## 当前实现

- 标准 Ultrahand 侧栏、448×720 双缓冲；截图前清空工具与通知层，本次编号和时效核对通过才截图。游戏不会被工具暂停。
- 后台使用 4 MiB 固定堆，保留全屏原始 JPEG；按实际长度释放截图缓冲，逐段编码上传，请求完成释放连接，HTTPS 校验开启。
- 标准含位置 OCR 的近邻碎片与连续行合并，按栏排列；正文默认聚焦，用户上下选择、触屏点选。L/R 合选相邻组，+ 重识别，刷新失败保留旧结果。
- 仅所选组进入阅读页时调用百度翻译；当前截图保留最近八个选择范围的结果。英文原句内可选词、手动扩词、在线查询；查词缓存各组共享并限制内存。
- 原子双槽消息、跨重启拒绝重放、请求编号隔离、超时与取消、联网期间心跳；B 从阅读页回到组列表，从列表退出后再次呼出正常 Ultrahand。
- 固定版本构建、独立设备诊断应用、带许可的安装与对应源码包、哈希清单和定向备份回退安装。
- 前后台配套版本与协议检查、统一版本来源；独立同学试用包及说明、固定安装白名单、可恢复卸载。试用包不覆盖 UH 或现有密钥配置，不附开发者密钥。

- 0.2.6 卡上最近一轮有 11 次识别成功，未记录识别错误；不得将其说成完成 50 次实机稳定性测试。
